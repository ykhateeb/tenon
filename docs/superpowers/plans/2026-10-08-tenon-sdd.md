# tenon-sdd Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `packages/tenon-sdd`, a pi package whose `/sdd` command runs the spec-driven workflow (5 stages, 3 human gates, full and small sizes) with code, not the model, in control of the stage order and the checks.

**Architecture:** Pure entities parse and change the workflow files (spec, area specs, plan, traceability, state). Use cases run the stages through two ports, `Agent` (a pi stage session) and `Person` (gates and dialogs), and use git, the shell, and JUnit reports directly. pi adapters implement the ports, register four model tools, and guard writes. `extension.ts` wires everything. Tenon loads the package as a built-in extension.

**Tech Stack:** TypeScript (ESM, `moduleResolution: bundler`), pi SDK `@earendil-works/pi-coding-agent` 1.0.x, `typebox` 1.x, Vitest 5, git CLI, Node 22+ (`fs.readdir` with `recursive` and `Dirent.parentPath`).

**Spec:** `docs/superpowers/specs/2026-10-08-tenon-sdd-design.md`. The workflow that the package runs: `~/Downloads/spec-driven-development-simple-workflow.md` (Task 16 copies it into the package).

## Global Constraints

- All code of the package is in `packages/tenon-sdd/`. Imports inside the package are relative and end in `.js` (for example `./result.js`). No `#` aliases inside the package.
- `entities/` imports only `entities/`. `use-cases/` imports `entities/`, `use-cases/`, and `adapters/git.ts`, `adapters/shell.ts`, `adapters/junit.ts`. `adapters/` imports `entities/` types, `use-cases/ports.ts`, `use-cases/stages.ts`, pi, and node. Only `extension.ts` imports all layers.
- No `any` in new code. State lives in `create…()` factories, not at module level.
- `@earendil-works/pi-coding-agent` and `typebox` are peer dependencies with the range `"*"`. Do not add them to `dependencies`.
- Branch name: `sdd/<YYYY-MM-DD>-<slug>`. Slug: lower case, hyphens, at most 5 words. Change folder: `sdd/changes/<YYYY-MM-DD>-<slug>/`.
- Commit message form: `sdd(<slug>): <event>`.
- The runner commits only on the change branch. It never pushes and never merges the change into the base.
- Command timeout: 30 minutes (`30 * 60 * 1000`). Failed exit checks before the person is asked: 3. Maximum review rounds with findings before G3: 2.
- Gate message custom type: `sdd-gate`. Session entry types: `sdd-stage`, `sdd-classify`, `sdd-return`, `sdd-review`.
- Tests that need files use `mkdtempSync(join(tmpdir(), "tenon-sdd-"))`.
- Each commit passes `npm run typecheck`, `npm test`, and `npm run build` (Tenon `CLAUDE.md`, "Change size").
- Comments and messages to the person and to the model are short, plain English (Simplified Technical English style).

## Review Focus

1. **Stale JUnit reports.** A report file from an earlier run must never make a stage pass. `runFullTier` deletes the report files before and after each run. Test: Task 10, "ignores a stale report from an earlier run".
2. **CRLF line ends.** A spec or rules file saved on Windows must parse the same. Tests: Task 1 (`rules.ts`) and Task 3 (`delta.ts`), "accepts CRLF line ends".
3. **A request with no Latin letters** (for example Arabic text) must still give a valid slug. Test: Task 11, `suggestSlug` returns `change`.
4. **Path forms in write and edit calls** (`./x`, an absolute path, mixed case) must hit the same guard rules. Test: Task 14, "normalizes the path before the policy".
5. **The person closes the slug dialog.** No branch and no files may appear. Test: Task 13, "does nothing when the person closes the slug dialog".

## Refinements of the spec

The plan refines the spec in these points. Each one comes from a verified pi or Tenon fact, or from a gap that the plan found.

1. **New files:** `entities/result.ts` (parse results), `entities/glob.ts` (glob matching), `entities/markdown.ts` (sections), `use-cases/change.ts` (change paths and files), `use-cases/areas.ts` (area spec loading), `use-cases/run-stage.ts` (the retry loop and the protected-path check), and `src/testing/` (test helpers, never imported by production code).
2. **Stage data and tool results go through session entries.** `ctx.newSession()` makes Tenon create a new pi runtime, so a new instance of the extension loads. The runner writes an `sdd-stage` custom entry (the write policy) into the new session in `setup`. The new instance reads it on `session_start`, sets the tools, and arms the guard. The tools report through `pi.appendEntry()` (`sdd-classify`, `sdd-return`, `sdd-review`). The runner reads the entries of the stage session after it is idle. `classify_change` does not write `state.json`. The runner does.
3. **`Person` has no `ask`.** `ask_owner` runs in the stage session and uses `ctx.ui` there.
4. **`ctx.ui.input(title, placeholder)` shows a hint, not a prefill** (Tenon `src/core/sessions/extension-ui.ts:60`). An empty answer means "use the suggestion".
5. **`state.json` has a `request` field**, so a resumed Spec stage still has the request.
6. **Test matching uses the last path part of the *Test* column.** `e2e/favorites-sorting-us1-s1` matches a test case whose name or class name contains `favorites-sorting-us1-s1`.
7. **The area spec is fully generated by code.** A baseline requirement has `(since <folder>, baseline)`. The Baseline section of `spec.md` can have a strict line `Coverage: <text>` for the Coverage section.
8. **JUnit report globs must start with a folder** (for example `reports/*.xml`), so the search does not walk `node_modules`.
9. **`/sdd` must run from the root folder of the git repository.**
10. **G3 covers the files that the branch changed** (from the fork point to the approval commit), except `state.json`. A base change to other files does not reopen G3.
11. **A docs change has no `traceability.md`.** Build checks only the full tier, and Ship links no tests.

```ts
export type ParseResult<T> = { ok: true; value: T } | { ok: false; errors: string[] };

export function parsed<T>(value: T, errors: readonly string[]): ParseResult<T> {
  return errors.length ? { ok: false, errors: [...errors] } : { ok: true, value };
}

export function errorsOf(result: ParseResult<unknown>): string[] {
  return result.ok ? [] : result.errors;
}
```

```ts
/**
 * A glob as a RegExp for paths relative to the project root, with "/" separators.
 * ponytail: supports `**`, `*`, and `?` only. Add braces or character classes if a project's globs need them.
 */
export function globToRegExp(glob: string): RegExp {
  let source = "";
  for (let i = 0; i < glob.length; i++) {
    const char = glob[i];
    if (char === "*" && glob[i + 1] === "*") {
      const isFolderPart = glob[i + 2] === "/";
      source += isFolderPart ? "(?:.*/)?" : ".*";
      i += isFolderPart ? 2 : 1;
    } else if (char === "*") source += "[^/]*";
    else if (char === "?") source += "[^/]";
    else source += char.replace(/[.+^${}()|[\]\\]/g, "\\$&");
  }
  return new RegExp(`^${source}$`);
}

export function matchesAny(path: string, globs: readonly string[]): boolean {
  return globs.some((glob) => globToRegExp(glob).test(path));
}

/** The folder before the first wildcard: where a search for the glob starts. */
export function globBase(glob: string): string {
  const parts = glob.split("/");
  return parts.slice(0, parts.findIndex((part) => /[*?]/.test(part))).join("/");
}
```

`packages/tenon-sdd/src/entities/rules.ts`:

```ts
import { globBase } from "./glob.js";
import { parsed, type ParseResult } from "./result.js";

export type Rules = {
  fullTier: string;
  junitReports: string[];
  fastTier: string | undefined;
  testFiles: string[];
  mutation: string | undefined;
  innerTdd: "optional" | "required";
};

const COMMAND_LINE = /^- ([A-Za-z ]+): (.+)$/;

/** Parse the Commands section of sdd/rules.md. All other text in the file is prose. */
export function parseRules(markdown: string): ParseResult<Rules> {
  const values = commandValues(markdown);
  const errors: string[] = [];
  const required = (key: string): string => {
    const value = values.get(key);
    if (!value) errors.push(`rules.md: the Commands section needs the line "- ${key}: …".`);
    return value ?? "";
  };
  const innerTdd = values.get("Inner TDD") ?? "optional";
  if (innerTdd !== "optional" && innerTdd !== "required") errors.push(`rules.md: "Inner TDD" must be optional or required, not "${innerTdd}".`);
  const mutation = values.get("Mutation");
  const rules: Rules = {
    fullTier: required("Full tier"),
    junitReports: list(required("JUnit reports")),
    fastTier: values.get("Fast tier"),
    testFiles: list(required("Test files")),
    mutation: mutation && mutation !== "none" ? mutation : undefined,
    innerTdd: innerTdd === "required" ? "required" : "optional",
  };
  for (const glob of rules.junitReports.filter((report) => globBase(report) === "")) {
    errors.push(`rules.md: the JUnit report glob "${glob}" must start with a folder, for example reports/*.xml.`);
  }
  return parsed(rules, errors);
}

function commandValues(markdown: string): Map<string, string> {
  const values = new Map<string, string>();
  let isCommands = false;
  for (const line of markdown.split(/\r?\n/).map((text) => text.trim())) {
    if (line.startsWith("## ")) isCommands = line === "## Commands";
    const match = isCommands ? COMMAND_LINE.exec(line) : null;
    if (match) values.set(match[1].trim(), match[2].trim());
  }
  return values;
}

function list(value: string): string[] {
  return value.split(",").map((item) => item.trim()).filter(Boolean);
}
```

```ts
import { parsed, type ParseResult } from "./result.js";

export const STAGES = ["spec", "plan", "tests", "build", "ship", "done"] as const;
export type Stage = (typeof STAGES)[number];
export type WorkStage = Exclude<Stage, "done">;
export const GATES = ["G1", "G2", "G3"] as const;
export type Gate = (typeof GATES)[number];
export type Size = "full" | "small";
export type ChangeType = "feature" | "change" | "bug" | "refactor" | "chore" | "docs";
export type Classification = { type: ChangeType; size: Size };

export type Approval = { gate: Gate; result: "approved"; commit: string; by: string; at: string };
export type Reopening = { gate: Gate; result: "reopened"; reason: string; by: string; at: string };
export type GateEntry = Approval | Reopening;

export type State = {
  owner: string;
  base: string;
  request: string;
  size?: Size;
  type?: ChangeType;
  specVersion: number;
  stage: Stage;
  reviewRounds: number;
  gates: GateEntry[];
};

const GATE_STAGE: Record<Gate, WorkStage> = { G1: "spec", G2: "tests", G3: "ship" };

export function parseState(json: string): ParseResult<State> {
  let value: unknown;
  try {
    value = JSON.parse(json);
  } catch (error) {
    return { ok: false, errors: [`state.json is not valid JSON: ${(error as Error).message}`] };
  }
  if (!isRecord(value)) return { ok: false, errors: ["state.json must hold an object."] };
  const errors: string[] = [];
  if (!STAGES.includes(value.stage as Stage)) errors.push(`state.json has an unknown stage "${String(value.stage)}".`);
  for (const key of ["owner", "base", "request"]) {
    if (typeof value[key] !== "string") errors.push(`state.json needs the text field "${key}".`);
  }
  if (!Array.isArray(value.gates)) errors.push('state.json needs the list "gates".');
  return parsed(value as State, errors);
}

/** The gate at the end of a stage. The small size has only G3. */
export function gateAfter(stage: Stage, size: Size | undefined): Gate | undefined {
  if (stage === "ship") return "G3";
  if (size === "small") return undefined;
  if (stage === "spec") return "G1";
  if (stage === "tests") return "G2";
  return undefined;
}

export function stageOf(gate: Gate): WorkStage {
  return GATE_STAGE[gate];
}

export function nextStage(state: State): Stage {
  const order = STAGES.filter((stage) => !(stage === "plan" && state.size === "small") && !(stage === "tests" && state.type === "docs"));
  return order[order.indexOf(state.stage) + 1] ?? "done";
}

/** The approval of a gate, if the last entry of that gate is an approval. */
export function approvalOf(state: State, gate: Gate): Approval | undefined {
  const last = state.gates.filter((entry) => entry.gate === gate).at(-1);
  return last?.result === "approved" ? last : undefined;
}

export function withApproval(state: State, approval: Omit<Approval, "result">): State {
  return {
    ...state,
    stage: approval.gate === "G3" ? "done" : state.stage,
    gates: [...state.gates, { ...approval, result: "approved" }],
  };
}

/** The return rule: go back to the target stage, and reopen each approved gate at or after it. */
export function returnedTo(state: State, { target, reason, by, at }: { target: WorkStage; reason: string; by: string; at: string }): State {
  const targetIndex = STAGES.indexOf(target);
  const reopened: Reopening[] = GATES.filter((gate) => STAGES.indexOf(GATE_STAGE[gate]) >= targetIndex && approvalOf(state, gate)).map((gate) => ({ gate, result: "reopened", reason, by, at }));
  const isSpecChange = target === "spec" && approvalOf(state, "G1") !== undefined;
  return {
    ...state,
    stage: target,
    specVersion: isSpecChange ? state.specVersion + 1 : state.specVersion,
    gates: [...state.gates, ...reopened],
  };
}

export function classificationError(state: State, { type, size }: Classification): string | undefined {
  if (type === "feature" && size === "small") return "A feature is always full size.";
  if (size === "small" && state.size === "full" && approvalOf(state, "G1")) return "A full change cannot become small after G1.";
  return undefined;
}

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === "object" && value !== null && !Array.isArray(value);
}
```

```ts
import { parsed, type ParseResult } from "./result.js";
import type { ChangeType, State } from "./state.js";

export type Story = { id: string; title: string; priority: number };
export type Scenario = { id: string; story: string; text: string };
export type DeltaItem =
  | { op: "ADDED"; area: string; id: string; text: string }
  | { op: "MODIFIED"; area: string; id: string; text: string; was: string }
  | { op: "REMOVED"; area: string; id: string; text: string; why: string };
export type BaselineItem = { area: string; id: string; text: string; intended: boolean; defect: string | undefined };
export type NewArea = { area: string; prefix: string };
export type Coverage = { area: string; text: string };
export type Spec = {
  stories: Story[];
  scenarios: Scenario[];
  delta: DeltaItem[];
  baseline: BaselineItem[];
  newAreas: NewArea[];
  coverage: Coverage[];
  openQuestions: string[];
  requirement: string | undefined;
};

const STORY = /^### (US\d+) — (.+) \(P(\d+)\)$/;
const SCENARIO = /^- \[(US\d+)-(S\d+)\] (.+)$/;
const AREA = /^### sdd\/areas\/([a-z0-9-]+)\.md(?: \(new, prefix ([A-Z]{2,8})\))?$/;
const DELTA_ITEM = /^- (ADDED|MODIFIED|REMOVED)\s+(\S+): (.+)$/;
const BASELINE_ITEM = /^- (BASE-[RQ]\d+): (.+)$/;
const COVERAGE = /^Coverage: (.+)$/;
const WAS = /^\(was: (.+)\)$/;
const WHY = /^\(why: (.+)\)$/;
const OPEN = /^- \[OPEN\] (.+)$/;
const REQUIREMENT = /(?:^|\s)Requirement: ([A-Z]{2,8}-[RQ]-\d{3,})(?:\s|$)/;
const NEW_ID = /^NEW-[RQ]\d+$/;
const EXISTING_ID = /^(?:[A-Z]{2,8}-[RQ]-\d{3,}|BASE-[RQ]\d+)$/;
const DELTA = "## Delta";
const BASELINE = "## Baseline (from code)";
const EMPTY_DELTA_TYPES: readonly ChangeType[] = ["bug", "refactor", "chore", "docs"];

type Line = { text: string; next: string; at: string };

/** Parse the strict lines of spec.md. All other text is prose. */
export function parseSpec(markdown: string): ParseResult<Spec> {
  const spec: Spec = { stories: [], scenarios: [], delta: [], baseline: [], newAreas: [], coverage: [], openQuestions: [], requirement: undefined };
  const errors: string[] = [];
  const texts = markdown.split(/\r?\n/).map((line) => line.trim());
  let section = "";
  let area: string | undefined;
  texts.forEach((text, index) => {
    if (text.startsWith("## ")) {
      section = text;
      area = undefined;
      return;
    }
    area = readAreaHeading(spec, text) ?? area;
    readCommonLine(spec, text);
    const line: Line = { text, next: texts[index + 1] ?? "", at: `spec.md line ${index + 1}` };
    if (section === DELTA) readDeltaLine(spec, errors, line, area);
    if (section === BASELINE) readBaselineLine(spec, errors, line, area);
  });
  return parsed(spec, [...errors, ...crossErrors(spec)]);
}

/** The rules that the type and the size put on the spec. */
export function sizeErrors(spec: Spec, { size, type }: Pick<State, "size" | "type">): string[] {
  if (!size || !type) return ["Call classify_change to set the type and the size of the change."];
  const errors: string[] = [];
  if (type === "feature" && size === "small") errors.push("A feature is always full size.");
  if (EMPTY_DELTA_TYPES.includes(type) && spec.delta.length) errors.push(`A ${type} has an empty delta.`);
  if (size === "small" && !isSmallDelta(spec.delta)) errors.push("A small change has an empty delta or one MODIFIED item.");
  if (size === "small" && (type === "bug" || type === "change") && !spec.requirement) errors.push(`A small ${type} needs the line "Requirement: <ID>".`);
  return errors;
}

function readAreaHeading(spec: Spec, text: string): string | undefined {
  const match = AREA.exec(text);
  if (!match) return undefined;
  const [, area, prefix] = match;
  if (prefix && !spec.newAreas.some((known) => known.area === area)) spec.newAreas.push({ area, prefix });
  return area;
}

function readCommonLine(spec: Spec, text: string): void {
  const requirement = REQUIREMENT.exec(text);
  if (requirement) spec.requirement = requirement[1];
  const open = OPEN.exec(text);
  if (open) spec.openQuestions.push(open[1]);
  const story = STORY.exec(text);
  if (story) spec.stories.push({ id: story[1], title: story[2], priority: Number(story[3]) });
  const scenario = SCENARIO.exec(text);
  if (scenario) spec.scenarios.push({ id: `${scenario[1]}-${scenario[2]}`, story: scenario[1], text: scenario[3] });
}

function readDeltaLine(spec: Spec, errors: string[], { text, next, at }: Line, area: string | undefined): void {
  const match = DELTA_ITEM.exec(text);
  if (!match) return;
  const [, op, id, itemText] = match;
  if (!area) {
    errors.push(`${at}: put a "### sdd/areas/<area>.md" heading above the delta item ${id}.`);
    return;
  }
  if (op === "ADDED") {
    if (!NEW_ID.test(id)) errors.push(`${at}: an ADDED ID looks like NEW-R1 or NEW-Q1, not ${id}.`);
    spec.delta.push({ op: "ADDED", area, id, text: itemText });
    return;
  }
  if (!EXISTING_ID.test(id)) errors.push(`${at}: a ${op} ID looks like FAV-R-002 or BASE-R1, not ${id}.`);
  if (op === "MODIFIED") {
    const was = WAS.exec(next);
    if (!was) errors.push(`${at}: put a "(was: …)" line below MODIFIED ${id}.`);
    spec.delta.push({ op: "MODIFIED", area, id, text: itemText, was: was?.[1] ?? "" });
    return;
  }
  const why = WHY.exec(next);
  if (!why) errors.push(`${at}: put a "(why: …)" line below REMOVED ${id}.`);
  spec.delta.push({ op: "REMOVED", area, id, text: itemText, why: why?.[1] ?? "" });
}

function readBaselineLine(spec: Spec, errors: string[], { text, next, at }: Line, area: string | undefined): void {
  const coverage = COVERAGE.exec(text);
  if (coverage && area) spec.coverage.push({ area, text: coverage[1] });
  const match = BASELINE_ITEM.exec(text);
  if (!match) return;
  const [, id, itemText] = match;
  if (!area) {
    errors.push(`${at}: put a "### sdd/areas/<area>.md" heading above the baseline item ${id}.`);
    return;
  }
  const intended = /Intended\? yes/.test(next) ? true : /Intended\? no/.test(next) ? false : undefined;
  if (intended === undefined) errors.push(`${at}: put "Intended? yes" or "Intended? no" below ${id}.`);
  const defect = /Defect: (.+?)(?:\s+Intended\?.*)?$/.exec(next)?.[1];
  spec.baseline.push({ area, id, text: itemText, intended: intended ?? true, defect });
}

function crossErrors(spec: Spec): string[] {
  const stories = new Set(spec.stories.map((story) => story.id));
  return [
    ...duplicates(spec.delta.map((item) => item.id)).map((id) => `The delta names ${id} more than one time.`),
    ...duplicates(spec.scenarios.map((scenario) => scenario.id)).map((id) => `The scenario ${id} is in spec.md more than one time.`),
    ...spec.scenarios.filter((scenario) => !stories.has(scenario.story)).map((scenario) => `The scenario ${scenario.id} has no story ${scenario.story}.`),
  ];
}

function duplicates(values: readonly string[]): string[] {
  return [...new Set(values.filter((value, index) => values.indexOf(value) !== index))];
}

function isSmallDelta(delta: readonly DeltaItem[]): boolean {
  return delta.length === 0 || (delta.length === 1 && delta[0].op === "MODIFIED");
}
```

```ts
import type { BaselineItem, DeltaItem } from "./delta.js";
import { parsed, type ParseResult } from "./result.js";

export type Requirement = { id: string; text: string; since: string; was: string | undefined };
export type TestLink = { id: string; test: string };
export type AreaSpec = {
  title: string;
  prefix: string;
  nextR: number;
  nextQ: number;
  coverage: string[];
  behavior: Requirement[];
  quality: Requirement[];
  tests: TestLink[];
  history: string[];
};
export type AreaChange = {
  folder: string;
  delta: readonly DeltaItem[];
  baseline: readonly BaselineItem[];
  coverage: string | undefined;
  tests: readonly TestLink[];
};

const TITLE = /^# Area spec: (.+)$/;
const HEADER = /^Prefix: ([A-Z]{2,8})\s+Next IDs: [A-Z]{2,8}-R-(\d+), [A-Z]{2,8}-Q-(\d+)$/;
const REQUIREMENT_LINE = /^- ([A-Z]{2,8}-[RQ]-\d{3,}): (.+?)\s+\(since ([^;)]+)(?:; was: ([^)]*))?\)$/;
const TEST_LINE = /^- ([A-Z]{2,8}-[RQ]-\d{3,}) → (.+)$/;
const LIST_LINE = /^- (.+)$/;
const FINAL_ID = /^[A-Z]{2,8}-[RQ]-\d{3,}$/;
const QUALITY_LOCAL_ID = /^(?:NEW|BASE)-Q\d+$/;

export function newArea(name: string, prefix: string): AreaSpec {
  const title = name.charAt(0).toUpperCase() + name.slice(1).replaceAll("-", " ");
  return { title, prefix, nextR: 1, nextQ: 1, coverage: [], behavior: [], quality: [], tests: [], history: [] };
}

export function isFinalId(id: string): boolean {
  return FINAL_ID.test(id);
}

export function hasRequirement(area: AreaSpec, id: string): boolean {
  return [...area.behavior, ...area.quality].some((requirement) => requirement.id === id);
}

export function parseAreaSpec(markdown: string): ParseResult<AreaSpec> {
  const area = newArea("area", "");
  area.title = "";
  let section = "";
  for (const line of markdown.split(/\r?\n/).map((text) => text.trim())) {
    if (line.startsWith("## ")) section = line.slice(3);
    else readAreaLine(area, section, line);
  }
  const errors = [
    ...(area.title ? [] : ['An area spec starts with "# Area spec: <title>".']),
    ...(area.prefix ? [] : ['An area spec needs the line "Prefix: ABC   Next IDs: ABC-R-001, ABC-Q-001".']),
  ];
  return parsed(area, errors);
}

export function renderAreaSpec(area: AreaSpec): string {
  const requirement = (r: Requirement) => `- ${r.id}: ${r.text}  (since ${r.since}${r.was ? `; was: ${r.was}` : ""})`;
  return [
    `# Area spec: ${area.title}`,
    `Prefix: ${area.prefix}   Next IDs: ${area.prefix}-R-${pad(area.nextR)}, ${area.prefix}-Q-${pad(area.nextQ)}`,
    ...(area.coverage.length ? ["", "## Coverage", ...area.coverage.map((text) => `- ${text}`)] : []),
    "",
    "## Current behavior",
    ...area.behavior.map(requirement),
    "",
    "## Quality requirements",
    ...area.quality.map(requirement),
    "",
    "## Tests",
    ...area.tests.map((link) => `- ${link.id} → ${link.test}`),
    "",
    "## History",
    ...area.history.map((line) => `- ${line}`),
    "",
  ].join("\n");
}

/** MODIFIED and REMOVED items whose text in the area spec is not what the delta expects. */
export function staleErrors(area: AreaSpec, items: readonly DeltaItem[]): string[] {
  const current = new Map([...area.behavior, ...area.quality].map((requirement) => [requirement.id, requirement.text]));
  return items.flatMap((item) => {
    if (item.op === "ADDED" || item.id.startsWith("BASE-")) return [];
    const expected = item.op === "MODIFIED" ? item.was : item.text;
    const actual = current.get(item.id);
    if (actual === undefined) return [`${item.id} is not in the area spec any more.`];
    return actual === expected ? [] : [`${item.id} changed in the area spec: it says "${actual}", and the delta expects "${expected}".`];
  });
}

/** Apply one change to an area spec: baseline, delta, test links, and one history line. */
export function applyChange(area: AreaSpec, change: AreaChange): { area: AreaSpec; ids: Map<string, string> } {
  const ids = new Map<string, string>();
  let { nextR, nextQ } = area;
  const assign = (localId: string): string => {
    const isQuality = QUALITY_LOCAL_ID.test(localId);
    const id = `${area.prefix}-${isQuality ? "Q" : "R"}-${pad(isQuality ? nextQ++ : nextR++)}`;
    ids.set(localId, id);
    return id;
  };
  const resolve = (id: string) => ids.get(id) ?? id;
  const requirements = new Map([...area.behavior, ...area.quality].map((requirement) => [requirement.id, requirement]));
  for (const item of change.baseline) {
    const id = assign(item.id);
    requirements.set(id, { id, text: item.text, since: `${change.folder}, baseline`, was: undefined });
  }
  for (const item of change.delta) {
    if (item.op === "ADDED") {
      const id = assign(item.id);
      requirements.set(id, { id, text: item.text, since: change.folder, was: undefined });
    } else if (item.op === "MODIFIED") {
      const id = resolve(item.id);
      requirements.set(id, { id, text: item.text, since: change.folder, was: requirements.get(id)?.text });
    } else requirements.delete(resolve(item.id));
  }
  const modified = new Set(change.delta.filter((item) => item.op === "MODIFIED").map((item) => resolve(item.id)));
  const links = change.tests.map((link) => ({ id: resolve(link.id), test: link.test }));
  const sorted = [...requirements.values()].sort((a, b) => compareText(a.id, b.id));
  const history = historyLine(change, resolve);
  return {
    ids,
    area: {
      ...area,
      nextR,
      nextQ,
      coverage: change.coverage ? [change.coverage] : area.coverage,
      behavior: sorted.filter((requirement) => requirement.id.includes("-R-")),
      quality: sorted.filter((requirement) => requirement.id.includes("-Q-")),
      tests: linkTests(area.tests, links, modified, requirements),
      history: history ? [history, ...area.history] : area.history,
    },
  };
}

function readAreaLine(area: AreaSpec, section: string, line: string): void {
  const title = TITLE.exec(line);
  if (title) area.title = title[1];
  const header = HEADER.exec(line);
  if (header) {
    area.prefix = header[1];
    area.nextR = Number(header[2]);
    area.nextQ = Number(header[3]);
  }
  const requirement = REQUIREMENT_LINE.exec(line);
  if (requirement && section === "Current behavior") area.behavior.push(toRequirement(requirement));
  if (requirement && section === "Quality requirements") area.quality.push(toRequirement(requirement));
  const test = TEST_LINE.exec(line);
  if (test && section === "Tests") area.tests.push({ id: test[1], test: test[2] });
  const item = LIST_LINE.exec(line);
  if (item && section === "History") area.history.push(item[1]);
  if (item && section === "Coverage") area.coverage.push(item[1]);
}

function toRequirement([, id, text, since, was]: RegExpExecArray): Requirement {
  return { id, text, since, was };
}

/** Old links stay, except the links of a MODIFIED requirement that has new links. Links of a removed requirement go. */
function linkTests(old: readonly TestLink[], added: readonly TestLink[], modified: ReadonlySet<string>, requirements: ReadonlyMap<string, Requirement>): TestLink[] {
  const relinked = new Set(added.filter((link) => modified.has(link.id)).map((link) => link.id));
  return [...old.filter((link) => !relinked.has(link.id)), ...added]
    .filter((link) => requirements.has(link.id))
    .filter((link, index, all) => all.findIndex((other) => other.id === link.id && other.test === link.test) === index)
    .sort((a, b) => compareText(a.id, b.id) || compareText(a.test, b.test));
}

function historyLine(change: AreaChange, resolve: (id: string) => string): string | undefined {
  const named = (op: DeltaItem["op"]) => change.delta.filter((item) => item.op === op).map((item) => resolve(item.id));
  const parts = [
    listed("baseline", change.baseline.map((item) => resolve(item.id))),
    listed("ADDED", named("ADDED")),
    listed("MODIFIED", named("MODIFIED")),
    listed("REMOVED", named("REMOVED")),
  ].filter(Boolean);
  if (!parts.length && change.tests.length) parts.push(listed("tests for", [...new Set(change.tests.map((link) => resolve(link.id)))]));
  return parts.length ? `${change.folder}: ${parts.join("; ")}` : undefined;
}

function listed(label: string, ids: readonly string[]): string {
  return ids.length ? `${label} ${ids.join(", ")}` : "";
}

function pad(n: number): string {
  return String(n).padStart(3, "0");
}

/** A plain comparison: localeCompare can ignore hyphens in some locales, and IDs must sort the same everywhere. */
function compareText(a: string, b: string): number {
  return a < b ? -1 : a > b ? 1 : 0;
}
```

```ts
import type { Spec } from "./delta.js";
import { parsed, type ParseResult } from "./result.js";

export type Task = {
  id: string;
  done: boolean;
  isTest: boolean;
  isParallel: boolean;
  refs: string[];
  file: string | undefined;
  phase: string;
};

const PHASE = /^### (.+)$/;
const TASK = /^- \[( |x)\] (T\d{3,}) (.*)$/;
const BRACKETS = /\[([^\]]+)\]/g;
const FILE = /\bin (\S+?)[;,]?(?=\s|$)/g;

/** Parse the task lines of plan.md: `- [ ] T001 (test) [P] [ID, ID] <text> in <file>`. */
export function parsePlan(markdown: string): ParseResult<Task[]> {
  const tasks: Task[] = [];
  let phase = "";
  for (const line of markdown.split(/\r?\n/).map((text) => text.trim())) {
    phase = PHASE.exec(line)?.[1] ?? phase;
    const task = TASK.exec(line);
    if (task) tasks.push(toTask(task, phase));
  }
  return parsed(tasks, tasks.length ? [] : ['plan.md has no task lines ("- [ ] T001 …").']);
}

/** Each delta ID has a task, each scenario has a test task, and parallel tasks do not share a file. */
export function consistencyErrors(tasks: readonly Task[], spec: Spec): string[] {
  const refs = new Set(tasks.flatMap((task) => task.refs));
  const testRefs = new Set(tasks.filter((task) => task.isTest).flatMap((task) => task.refs));
  return [
    ...spec.delta.filter((item) => !refs.has(item.id)).map((item) => `No task names ${item.id}.`),
    ...spec.scenarios.filter((scenario) => !testRefs.has(scenario.id)).map((scenario) => `No (test) task names ${scenario.id}.`),
    ...parallelClashes(tasks),
  ];
}

function toTask([, mark, id, rest]: RegExpExecArray, phase: string): Task {
  const groups = [...rest.matchAll(BRACKETS)].map((match) => match[1]);
  return {
    id,
    done: mark === "x",
    isTest: rest.includes("(test)"),
    isParallel: groups.includes("P"),
    refs: groups.filter((group) => group !== "P").flatMap((group) => group.split(",").map((ref) => ref.trim())),
    file: [...rest.matchAll(FILE)].at(-1)?.[1],
    phase,
  };
}

function parallelClashes(tasks: readonly Task[]): string[] {
  const owners = new Map<string, string>();
  const errors: string[] = [];
  for (const task of tasks.filter((candidate) => candidate.isParallel && candidate.file)) {
    const key = `${task.phase}\n${task.file}`;
    const owner = owners.get(key);
    if (owner) errors.push(`${owner} and ${task.id} run in parallel but both change ${task.file}.`);
    else owners.set(key, task.id);
  }
  return errors;
}
```

```ts
import type { TestLink } from "./area-spec.js";
import type { Spec } from "./delta.js";
import type { ParseResult } from "./result.js";

export type TestResult = "passed" | "failed" | "skipped";
export type TestCase = { name: string; className: string; result: TestResult };
export type Row = { id: string; scenario: string; level: string; test: string; status: string; evidence: string; verdict: string };
export type Traceability = { head: string[]; rows: Row[]; footer: string[] };
/** fail-first: a new test must fail before the build. pass: each test must pass. */
export type TestMode = "fail-first" | "pass";

export const REMOVED = "REMOVED";
export const CHARACTERIZATION = "Characterization";
export const EXPECTED_FAILURE = "failing (expected)";
const GONE = "—";
const COLUMNS = ["ID", "Scenario", "Level", "Test", "Status", "Evidence", "Verdict"];
const REQUIREMENT_ID = /^(?:NEW-[RQ]\d+|BASE-[RQ]\d+|[A-Z]{2,8}-[RQ]-\d{3,})$/;

export function parseTraceability(markdown: string): ParseResult<Traceability> {
  const lines = markdown.split(/\r?\n/);
  const start = lines.findIndex((line) => cells(line).join("|") === COLUMNS.join("|"));
  if (start < 0) return { ok: false, errors: [`traceability.md needs a table with the columns ${COLUMNS.join(" | ")}.`] };
  let end = start + 2;
  while (end < lines.length && lines[end].trim().startsWith("|")) end++;
  return { ok: true, value: { head: lines.slice(0, start), rows: lines.slice(start + 2, end).map((line) => toRow(cells(line))), footer: lines.slice(end) } };
}

export function renderTraceability(trace: Traceability): string {
  const line = (values: readonly string[]) => `| ${values.join(" | ")} |`;
  const rows = trace.rows.map((row) => line([row.id, row.scenario, row.level, row.test, row.status, row.evidence, row.verdict]));
  return [...trace.head, line(COLUMNS), `|${COLUMNS.map(() => "---").join("|")}|`, ...rows, ...trace.footer].join("\n");
}

/** The name part of the Test column that a JUnit test case must contain: the last path part of its first word. */
export function keyOf(row: Row): string {
  const word = row.test.split(/\s+/)[0] ?? "";
  return word.slice(word.lastIndexOf("/") + 1);
}

export function withStatuses(rows: readonly Row[], cases: readonly TestCase[], mode: TestMode): Row[] {
  return rows.map((row) => (row.verdict === "extra" ? row : { ...row, status: statusOf(row, cases, mode) }));
}

export function testsStageErrors(rows: readonly Row[], spec: Spec, mode: TestMode): string[] {
  const missing = [
    ...spec.scenarios.filter((scenario) => !rows.some((row) => row.scenario === scenario.id)).map((scenario) => `No row for the scenario ${scenario.id}.`),
    ...spec.delta.filter((item) => !rows.some((row) => row.id === item.id)).map((item) => `No row for ${item.id}.`),
  ];
  const wrong = rows.filter((row) => row.verdict !== "extra").flatMap((row) => {
    const wanted = wantedStatus(row, mode);
    return row.status === wanted ? [] : [`${row.id} ${row.scenario}: ${row.test} is "${row.status}", and it must be "${wanted}".`];
  });
  return [...missing, ...wrong];
}

export function withVerdicts(rows: readonly Row[], hasFile: (path: string) => boolean): Row[] {
  return rows.map((row) => {
    if (row.verdict === "extra") return row;
    if (row.scenario === REMOVED) return { ...row, verdict: GONE };
    const files = row.evidence.split(",").map((file) => file.trim()).filter(Boolean);
    const isMet = row.status === "passing" && files.length > 0 && files.every(hasFile);
    return { ...row, verdict: isMet ? "met" : "missing" };
  });
}

export function buildStageErrors(rows: readonly Row[]): string[] {
  return rows.flatMap((row) => {
    if (row.verdict === "extra") return [`Extra code with no requirement: ${row.evidence || row.test}. Remove it, or use request_return to add it to the spec.`];
    if (row.scenario === REMOVED) return row.status === GONE ? [] : [`The deleted test ${keyOf(row)} of REMOVED ${row.id} still runs.`];
    return row.verdict === "met" ? [] : [`${row.id} ${row.scenario}: the test is "${row.status}", and the evidence is "${row.evidence || "empty"}".`];
  });
}

/** The test links that Ship writes into the area specs. */
export function requirementLinks(rows: readonly Row[]): TestLink[] {
  return rows
    .filter((row) => REQUIREMENT_ID.test(row.id) && row.scenario !== REMOVED && row.verdict !== "extra" && keyOf(row) !== "")
    .map((row) => ({ id: row.id, test: keyOf(row) }));
}

function statusOf(row: Row, cases: readonly TestCase[], mode: TestMode): string {
  const key = keyOf(row);
  const found = key ? cases.filter((testCase) => testCase.name.includes(key) || testCase.className.includes(key)) : [];
  if (row.scenario === REMOVED) return found.length ? "still runs" : GONE;
  if (!found.length) return "not found";
  if (found.some((testCase) => testCase.result === "skipped")) return "skipped";
  if (!found.some((testCase) => testCase.result === "failed")) return "passing";
  return mode === "fail-first" && row.level !== CHARACTERIZATION ? EXPECTED_FAILURE : "failing";
}

function wantedStatus(row: Row, mode: TestMode): string {
  if (row.scenario === REMOVED) return GONE;
  return mode === "pass" || row.level === CHARACTERIZATION ? "passing" : EXPECTED_FAILURE;
}

function cells(line: string): string[] {
  const text = line.trim();
  if (!text.startsWith("|")) return [];
  return text.slice(1, text.endsWith("|") ? -1 : undefined).split("|").map((cell) => cell.trim());
}

function toRow(values: readonly string[]): Row {
  const [id = "", scenario = "", level = "", test = "", status = "", evidence = "", verdict = ""] = values;
  return { id, scenario, level, test, status, evidence, verdict };
}
```

```ts
import { matchesAny } from "./glob.js";

export type StageKind = "setup" | "spec" | "plan" | "tests" | "build" | "review";
export type Policy = { kind: StageKind; changeDir: string; specLocked: boolean; lockedTests: string[]; testGlobs: string[] };

type Allowed = { files: string[]; tests?: true; everything?: true };

const ALLOWED: Record<StageKind, (dir: string) => Allowed> = {
  setup: () => ({ files: ["sdd/rules.md"] }),
  spec: (dir) => ({ files: [`${dir}/spec.md`] }),
  plan: (dir) => ({ files: [`${dir}/plan.md`] }),
  tests: (dir) => ({ files: [`${dir}/traceability.md`, `${dir}/plan.md`], tests: true }),
  build: () => ({ files: [], everything: true }),
  review: (dir) => ({ files: [`${dir}/outcome.md`] }),
};

/**
 * Why a stage cannot write a path, or undefined if it can.
 * The file systems of macOS and Windows ignore case, so the check does too.
 */
export function blockReason(path: string, policy: Policy): string | undefined {
  const target = path.toLowerCase();
  const dir = policy.changeDir.toLowerCase();
  return protectedReason(target, dir, policy) ?? stageReason(target, dir, policy);
}

function protectedReason(target: string, dir: string, policy: Policy): string | undefined {
  if (target === ".." || target.startsWith("../")) return "Write only inside the project.";
  if (target === `${dir}/state.json`) return "state.json changes only through the runner.";
  if (target.startsWith("sdd/areas/")) return "Only Ship changes the area specs. Write the change in the delta of spec.md.";
  if (target === "sdd/rules.md" && policy.kind !== "setup") return "rules.md changes only by review, not inside a change.";
  if (target.startsWith("sdd/changes/") && !target.startsWith(`${dir}/`)) return "The folders of other changes are frozen.";
  if (policy.specLocked && target === `${dir}/spec.md`) return "spec.md is approved (G1). Use request_return with the stage spec.";
  if (policy.lockedTests.some((test) => test.toLowerCase() === target)) return "This test is approved (G2). Use request_return with the stage tests.";
  return undefined;
}

function stageReason(target: string, dir: string, policy: Policy): string | undefined {
  const allowed = ALLOWED[policy.kind](dir);
  const isTestFile = allowed.tests === true && matchesAny(target, policy.testGlobs.map((glob) => glob.toLowerCase()));
  if (allowed.everything || isTestFile || allowed.files.includes(target)) return undefined;
  const names = [...allowed.files, ...(allowed.tests ? ["test files"] : [])];
  return `In the ${policy.kind} stage you can write only ${names.join(", ")}.`;
}
```

```ts
/** Replace the section `## <heading>` up to the next `## ` heading, or add it at the end. */
export function upsertSection(markdown: string, heading: string, body: string): string {
  const lines = markdown.replace(/\s+$/, "").split(/\r?\n/);
  const section = [`## ${heading}`, ...body.split("\n")];
  const start = lines.findIndex((line) => line.trim() === `## ${heading}`);
  if (start < 0) return [...lines, "", ...section, ""].join("\n");
  const next = lines.findIndex((line, index) => index > start && line.startsWith("## "));
  const rest = next < 0 ? [] : ["", ...lines.slice(next)];
  return [...lines.slice(0, start), ...section, ...rest, ""].join("\n");
}

export function hasSection(markdown: string, heading: string): boolean {
  return markdown.split(/\r?\n/).some((line) => line.trim() === `## ${heading}`);
}
```

```ts
import { readFile, readdir, rm } from "node:fs/promises";
import { join, relative, sep } from "node:path";
import { globBase, globToRegExp } from "../entities/glob.js";
import type { TestCase, TestResult } from "../entities/traceability.js";

const TESTCASE = /<testcase\b([^>]*?)(?:\/>|>([\s\S]*?)<\/testcase>)/g;
const ENTITIES: Record<string, string> = { lt: "<", gt: ">", quot: '"', apos: "'", amp: "&" };

/**
 * The test cases of a JUnit XML report.
 * ponytail: reads <testcase> elements with a regex, not a full XML parser. Use an XML library if a test tool writes JUnit that this cannot read.
 */
export function parseJunit(xml: string): TestCase[] {
  return [...xml.matchAll(TESTCASE)].map(([, attributes, body = ""]) => ({
    name: attribute(attributes, "name"),
    className: attribute(attributes, "classname"),
    result: resultOf(body),
  }));
}

export async function readReports(root: string, globs: readonly string[]): Promise<{ cases: TestCase[]; missing: string[] }> {
  const cases: TestCase[] = [];
  const missing: string[] = [];
  for (const glob of globs) {
    const files = await findFiles(root, glob);
    if (!files.length) missing.push(glob);
    for (const file of files) cases.push(...parseJunit(await readFile(join(root, file), "utf8")));
  }
  return { cases, missing };
}

export async function removeReports(root: string, globs: readonly string[]): Promise<void> {
  for (const glob of globs) {
    for (const file of await findFiles(root, glob)) await rm(join(root, file), { force: true });
  }
}

/** Files under the folder part of the glob that match it. A missing folder gives no files. */
async function findFiles(root: string, glob: string): Promise<string[]> {
  const pattern = globToRegExp(glob);
  const entries = await readdir(join(root, globBase(glob)), { recursive: true, withFileTypes: true }).catch(() => []);
  return entries
    .filter((entry) => entry.isFile())
    .map((entry) => relative(root, join(entry.parentPath, entry.name)).split(sep).join("/"))
    .filter((path) => pattern.test(path));
}

function resultOf(body: string): TestResult {
  if (/<(failure|error)\b/.test(body)) return "failed";
  if (/<skipped\b/.test(body)) return "skipped";
  return "passed";
}

function attribute(attributes: string, name: string): string {
  const value = new RegExp(`\\b${name}="([^"]*)"`).exec(attributes)?.[1] ?? "";
  return value.replace(/&(lt|gt|quot|apos|amp);/g, (_, entity: string) => ENTITIES[entity]);
}
```

```ts
import { spawn } from "node:child_process";

export type CommandResult = { code: number | null; output: string; timedOut: boolean };

const MAX_OUTPUT = 20_000;

/** Run a shell command in a folder. Keep the last part of stdout and stderr. Stop it after the timeout. */
export function runCommand(command: string, { cwd, timeoutMs }: { cwd: string; timeoutMs: number }): Promise<CommandResult> {
  return new Promise((resolve) => {
    const child = spawn(command, { cwd, shell: true, detached: true });
    let output = "";
    let timedOut = false;
    const keep = (chunk: Buffer) => {
      output = (output + chunk.toString()).slice(-MAX_OUTPUT);
    };
    child.stdout.on("data", keep);
    child.stderr.on("data", keep);
    const timer = setTimeout(() => {
      timedOut = true;
      stopGroup(child.pid);
    }, timeoutMs);
    child.on("error", (error) => {
      clearTimeout(timer);
      resolve({ code: null, output: `${output}${error.message}\n`, timedOut });
    });
    child.on("close", (code) => {
      clearTimeout(timer);
      resolve({ code, output, timedOut });
    });
  });
}

/** ponytail: stops the POSIX process group. On Windows, only the shell stops. */
function stopGroup(pid: number | undefined): void {
  if (pid === undefined) return;
  try {
    process.kill(-pid, "SIGKILL");
  } catch {
    // The group already ended.
  }
}
```

```ts
import { execFile } from "node:child_process";
import { rm } from "node:fs/promises";
import { join } from "node:path";
import { promisify } from "node:util";

const execFileAsync = promisify(execFile);
const MAX_BUFFER = 64 * 1024 * 1024;

export type MergeResult = { ok: true } | { ok: false; output: string };
export type Git = ReturnType<typeof createGit>;

/** git commands in one repository. Each failure names the command. */
export function createGit(root: string) {
  async function git(...args: string[]): Promise<string> {
    try {
      const { stdout } = await execFileAsync("git", args, { cwd: root, maxBuffer: MAX_BUFFER });
      return stdout.trim();
    } catch (error) {
      throw new Error(`git ${args.join(" ")} failed: ${outputOf(error)}`, { cause: error });
    }
  }
  const succeeds = (...args: string[]) => git(...args).then(() => true, () => false);
  const lines = (text: string) => text.split("\n").filter(Boolean);

  return {
    isRepository: () => succeeds("rev-parse", "--is-inside-work-tree"),
    root: () => git("rev-parse", "--show-toplevel"),
    currentBranch: () => git("branch", "--show-current"),
    head: () => git("rev-parse", "HEAD"),
    userName: async () => (await git("config", "user.name").catch(() => "")) || "unknown",
    isClean: async () => (await git("status", "--porcelain")) === "",
    /** True while a merge waits for the person to resolve its conflicts. */
    isMerging: () => succeeds("rev-parse", "-q", "--verify", "MERGE_HEAD"),
    /** True if a local or a remote branch matches the pattern, for example sdd/*-sort. */
    branchExists: async (pattern: string) => (await git("for-each-ref", "--format=%(refname)", `refs/heads/${pattern}`, `refs/remotes/*/${pattern}`)) !== "",
    createBranch: async (name: string) => {
      await git("switch", "-q", "-c", name);
    },
    /** Commit all work. Returns the new commit, or undefined if there was nothing to commit. */
    commitAll: async (message: string) => {
      await git("add", "-A");
      if (await succeeds("diff", "--cached", "--quiet")) return undefined;
      await git("commit", "-q", "-m", message);
      return git("rev-parse", "HEAD");
    },
    /** Merge the base into the current branch. A conflict stays in the tree for the person to resolve. */
    mergeBase: async (base: string): Promise<MergeResult> => {
      try {
        await git("merge", "-q", "--no-edit", base);
        return { ok: true };
      } catch (error) {
        return { ok: false, output: (error as Error).message };
      }
    },
    forkPoint: (base: string, ref = "HEAD") => git("merge-base", ref, base),
    changedBetween: async (from: string, to: string) => lines(await git("diff", "--name-only", from, to)),
    /** Tracked files that differ from the commit, and untracked files, in these paths. */
    changedSince: async (commit: string, paths: readonly string[]) => {
      if (!paths.length) return [];
      const tracked = lines(await git("diff", "--name-only", commit, "--", ...paths));
      const untracked = lines(await git("ls-files", "--others", "--exclude-standard", "--", ...paths));
      return [...new Set([...tracked, ...untracked])];
    },
    /** Put the files back as they are in the commit. A file that the commit does not have is deleted. */
    restore: async (commit: string, paths: readonly string[]) => {
      for (const path of paths) {
        if (await succeeds("cat-file", "-e", `${commit}:${path}`)) await git("checkout", commit, "--", path);
        else await rm(join(root, path), { force: true });
      }
    },
    isCommitted: (path: string) => succeeds("cat-file", "-e", `HEAD:${path}`),
    fileAt: (ref: string, path: string) => git("show", `${ref}:${path}`).catch(() => undefined),
    diff: (from: string, paths: readonly string[] = []) => git("diff", from, "HEAD", "--", ...paths),
    diffStat: (from: string) => git("diff", "--stat", from, "HEAD"),
  };
}

function outputOf(error: unknown): string {
  const { stderr, message } = error as { stderr?: string; message?: string };
  return (stderr || message || String(error)).trim();
}
```

```ts
import type { Deps } from "./ports.js";

export type FullTier = { code: number | null; output: string; cases: TestCase[]; errors: string[] };

const OUTPUT_TAIL = 4000;
const OUTCOME_SECTIONS = ["Delivered", "Evidence", "Changed after approval", "Left open"];

/** Run the full tier and read its JUnit reports. Old reports are deleted first, so a stale report cannot pass. */
export async function runFullTier(deps: Deps, rules: Rules): Promise<FullTier> {
  await removeReports(deps.root, rules.junitReports);
  const result = await runCommand(rules.fullTier, { cwd: deps.root, timeoutMs: deps.timeoutMs });
  const output = result.output.slice(-OUTPUT_TAIL);
  if (result.timedOut) {
    return { code: result.code, output, cases: [], errors: [`The full tier ran longer than ${deps.timeoutMs / 60_000} minutes and was stopped. Output:\n${output}`] };
  }
  const { cases, missing } = await readReports(deps.root, rules.junitReports);
  await removeReports(deps.root, rules.junitReports);
  return { code: result.code, output, cases, errors: missing.map((glob) => `The full tier wrote no JUnit report that matches ${glob}. Output:\n${output}`) };
}

export async function setupErrors(deps: Deps): Promise<string[]> {
  const text = await readText(deps.root, RULES_PATH);
  if (text === undefined) return [`Write ${RULES_PATH}.`];
  const rules = parseRules(text);
  return rules.ok ? (await runFullTier(deps, rules.value)).errors : rules.errors;
}

/** The exit check of the current stage. Ship has its own check (shipErrors). */
export async function exitErrors(deps: Deps, change: Change, state: State, rules: Rules): Promise<string[]> {
  if (state.stage === "spec") return specErrors(deps, change, state);
  if (state.stage === "plan") return planErrors(change);
  if (state.stage === "tests") return testsErrors(deps, change, state, rules);
  if (state.stage === "build") return buildErrors(deps, change, state, rules);
  return [];
}

export async function shipErrors(deps: Deps, rules: Rules, change: Change, isReviewed: boolean): Promise<string[]> {
  const outcome = (await readText(deps.root, pathOf(change, "outcome.md"))) ?? "";
  const tier = await runFullTier(deps, rules);
  return [
    ...(isReviewed ? [] : ["Call report_review with your findings. Give an empty list if there are none."]),
    ...OUTCOME_SECTIONS.filter((section) => !hasSection(outcome, section)).map((section) => `outcome.md needs the section "## ${section}".`),
    ...(tier.errors.length ? tier.errors : failingCases(tier)),
  ];
}

export function failingCases(tier: FullTier): string[] {
  const failed = tier.cases.filter((testCase) => testCase.result === "failed").map((testCase) => testCase.name);
  if (failed.length) return [`The full tier has failing tests: ${failed.join(", ")}.`];
  return tier.code === 0 ? [] : [`The full tier exited with the code ${tier.code ?? "none"}. Output:\n${tier.output}`];
}

async function specErrors(deps: Deps, change: Change, state: State): Promise<string[]> {
  const spec = await readSpec(change);
  if (!spec.ok) return spec.errors;
  return [
    ...spec.value.openQuestions.map((question) => `An open question is left: "${question}". Ask the owner with ask_owner, and write the answer into the spec.`),
    ...sizeErrors(spec.value, state),
    ...(await dryRunErrors(deps.root, spec.value)),
  ];
}

/** The delta against the area specs of the working tree: each MODIFIED and REMOVED item must still match. */
async function dryRunErrors(root: string, spec: Spec): Promise<string[]> {
  const errors: string[] = [];
  for (const name of areasOf(spec)) {
    const area = areaFrom(name, await readText(root, `${AREAS_DIR}/${name}.md`), spec);
    errors.push(...(area.ok ? staleErrors(area.value, spec.delta.filter((item) => item.area === name)) : area.errors));
  }
  if (spec.requirement && !(await requirementExists(root, spec.requirement))) errors.push(`No area spec has the requirement ${spec.requirement}.`);
  return errors;
}

async function requirementExists(root: string, id: string): Promise<boolean> {
  const areas = await readAreas(root);
  const name = areaWithPrefix(areas, id);
  const area = name === undefined ? undefined : areas.get(name);
  return area !== undefined && hasRequirement(area, id);
}

async function planErrors(change: Change): Promise<string[]> {
  const [spec, plan] = await Promise.all([readSpec(change), readPlan(change)]);
  if (!spec.ok || !plan.ok) return [...errorsOf(spec), ...errorsOf(plan)];
  return consistencyErrors(plan.value, spec.value);
}

async function testsErrors(deps: Deps, change: Change, state: State, rules: Rules): Promise<string[]> {
  const [spec, trace] = await Promise.all([readSpec(change), readTrace(change)]);
  if (!spec.ok || !trace.ok) return [...errorsOf(spec), ...errorsOf(trace)];
  const unticked = state.size === "full" ? await untickedErrors(change, true) : [];
  const tier = await runFullTier(deps, rules);
  if (tier.errors.length) return [...unticked, ...tier.errors];
  const mode: TestMode = state.type === "refactor" || state.type === "chore" ? "pass" : "fail-first";
  const rows = withStatuses(trace.value.rows, tier.cases, mode);
  await writeTrace(change, { ...trace.value, rows });
  return [...unticked, ...testsStageErrors(rows, spec.value, mode)];
}

async function buildErrors(deps: Deps, change: Change, state: State, rules: Rules): Promise<string[]> {
  const unticked = state.size === "full" ? await untickedErrors(change, false) : [];
  const tier = await runFullTier(deps, rules);
  if (tier.errors.length) return [...unticked, ...tier.errors];
  if (state.type === "docs") return [...unticked, ...failingCases(tier)];
  const trace = await readTrace(change);
  if (!trace.ok) return [...unticked, ...trace.errors];
  const rows = withVerdicts(withStatuses(trace.value.rows, tier.cases, "pass"), (path) => existsSync(join(deps.root, path)));
  await writeTrace(change, { ...trace.value, rows });
  return [...unticked, ...failingCases(tier), ...buildStageErrors(rows), ...(await mutationErrors(deps, rules))];
}

async function untickedErrors(change: Change, onlyTests: boolean): Promise<string[]> {
  const plan = await readPlan(change);
  if (!plan.ok) return plan.errors;
  return plan.value.filter((task) => !task.done && (!onlyTests || task.isTest)).map((task) => `Tick the task ${task.id} in plan.md when it is done.`);
}

async function mutationErrors(deps: Deps, rules: Rules): Promise<string[]> {
  if (!rules.mutation) return [];
  const result = await runCommand(rules.mutation, { cwd: deps.root, timeoutMs: deps.timeoutMs });
  if (result.code === 0) return [];
  return [
    `The mutation command failed (exit code ${result.code ?? "none"}): the score is below the minimum, or the command broke. Make the weak tests stronger. If a weak test is approved, use request_return with the stage tests. Output:\n${result.output.slice(-OUTPUT_TAIL)}`,
  ];
}
```

```ts
import { mkdir, readdir } from "node:fs/promises";
import { join } from "node:path";
import type { State } from "../entities/state.js";
import { changeOf, isoDate, writeState, type Change } from "./change.js";
import type { Deps } from "./ports.js";

const MAX_SLUG_WORDS = 5;
const FALLBACK_SLUG = "change";
const DATE_PREFIX_LENGTH = "YYYY-MM-DD-".length;

/** A short name from the request: lower case Latin letters and digits, at most 5 words. */
export function suggestSlug(request: string): string {
  const words = request.toLowerCase().replace(/[^a-z0-9]+/g, " ").trim().split(" ").filter(Boolean);
  return words.slice(0, MAX_SLUG_WORDS).join("-") || FALLBACK_SLUG;
}

/** Make the branch and the change folder, write the first state.json, and commit it. */
export async function startChange(deps: Deps, { request, slug }: { request: string; slug: string }): Promise<Change> {
  const unique = await uniqueSlug(deps, slug);
  const folder = `${isoDate(deps.now())}-${unique}`;
  const base = await deps.git.currentBranch();
  await deps.git.createBranch(`sdd/${folder}`);
  const change = changeOf(deps.root, `sdd/${folder}`);
  if (!change) throw new Error(`The branch name sdd/${folder} is not valid.`);
  await mkdir(join(deps.root, change.dir), { recursive: true });
  const state: State = { owner: await deps.git.userName(), base, request, specVersion: 1, stage: "spec", reviewRounds: 0, gates: [] };
  await writeState(change, state);
  await deps.git.commitAll(`sdd(${unique}): start`);
  return change;
}

/** The slug, or the slug with -2, -3, … if a change folder or a branch already uses it. Test names start with the slug, so it must be unique. */
async function uniqueSlug(deps: Deps, slug: string): Promise<string> {
  const folders = await readdir(join(deps.root, "sdd/changes")).catch(() => []);
  const used = new Set(folders.map((name) => name.slice(DATE_PREFIX_LENGTH)));
  for (let n = 1; ; n++) {
    const candidate = n === 1 ? slug : `${slug}-${n}`;
    if (!used.has(candidate) && !(await deps.git.branchExists(`sdd/*-${candidate}`))) return candidate;
  }
}
```

```ts
import type { State } from "../entities/state.js";
import type { Policy } from "../entities/write-policy.js";
import { AREAS_DIR, pathOf, readText, RULES_PATH, stateText, writeState, type Change } from "./change.js";
import type { Deps, ReturnRequest, StageOutcome, StageRun } from "./ports.js";

export type StageEnd = { kind: "passed" } | { kind: "stopped" } | { kind: "returned"; request: ReturnRequest };
export type CheckedRun = {
  runs: readonly StageRun[];
  protect: () => Promise<string[]>;
  apply: (outcome: StageOutcome) => Promise<void>;
  check: () => Promise<string[]>;
};

const CHECKS_BEFORE_ASKING = 3;
const TRY_AGAIN = "Try again";

/**
 * Run the sessions of a stage, then the protected-path check and the exit check.
 * A failed check goes to the last session as a follow-up message. After each 3 failed checks, the person decides.
 */
export async function runChecked(deps: Deps, { runs, protect, apply, check }: CheckedRun): Promise<StageEnd> {
  for (const run of runs) {
    const end = await settle(await deps.agent.run(run), apply);
    if (end) return end;
  }
  for (let failures = 0; ; ) {
    const errors = [...(await protect()), ...(await check())];
    if (!errors.length) return { kind: "passed" };
    failures++;
    if (failures % CHECKS_BEFORE_ASKING === 0 && !(await shouldTryAgain(deps, runs[0]?.title ?? "sdd", failures))) return { kind: "stopped" };
    const end = await settle(await deps.agent.followUp(failureMessage(errors)), apply);
    if (end) return end;
  }
}

/**
 * The bash gap: the tool_call guard cannot see files that bash writes.
 * Restore each protected file that changed since the last commit, and state.json if it is not the state of the runner.
 */
export async function protectedErrors(deps: Deps, change: Change, policy: Policy, state: State): Promise<string[]> {
  const own = [AREAS_DIR, ...(policy.kind === "setup" ? [] : [RULES_PATH]), ...(policy.specLocked ? [pathOf(change, "spec.md")] : []), ...policy.lockedTests];
  const otherChanges = ["sdd/changes", `:(exclude)${change.dir}`];
  const changed = [...(await deps.git.changedSince("HEAD", own)), ...(await deps.git.changedSince("HEAD", otherChanges))];
  const errors: string[] = [];
  if (changed.length) {
    await deps.git.restore("HEAD", changed);
    errors.push(`You changed ${changed.join(", ")}, which this stage cannot change. The runner restored the files. Use request_return if a change there is necessary.`);
  }
  if ((await readText(deps.root, pathOf(change, "state.json"))) !== stateText(state)) {
    await writeState(change, state);
    errors.push("You changed state.json. The runner restored it. Only the runner changes state.json.");
  }
  return errors;
}

async function settle(outcome: StageOutcome, apply: CheckedRun["apply"]): Promise<StageEnd | undefined> {
  if (outcome.aborted) return { kind: "stopped" };
  if (outcome.returnRequest) return { kind: "returned", request: outcome.returnRequest };
  await apply(outcome);
  return undefined;
}

async function shouldTryAgain(deps: Deps, title: string, failures: number): Promise<boolean> {
  return (await deps.person.choose(`${title}: the exit check failed ${failures} times.`, [TRY_AGAIN, "Stop"])) === TRY_AGAIN;
}

function failureMessage(errors: readonly string[]): string {
  return ["The exit check of this stage failed. Correct these items, then stop:", ...errors.map((error) => `- ${error}`)].join("\n");
}
```

```ts
/** Approved gates with a covered file that changed after the approval, earliest first. */
export async function invalidGates(deps: Deps, change: Change, state: State, rules: Rules): Promise<Gate[]> {
  const invalid: Gate[] = [];
  for (const gate of GATES) {
    const approval = approvalOf(state, gate);
    if (!approval) continue;
    const covered = await coveredPaths(deps, change, state, rules, gate, approval.commit);
    if ((await deps.git.changedSince(approval.commit, covered)).length) invalid.push(gate);
  }
  return invalid;
}

/** The text that the person reads before a gate. */
export async function gateSummary(deps: Deps, change: Change, gate: Gate, state: State, rules: Rules): Promise<string> {
  const file = async (path: string) => `### ${path}\n\n${(await readText(deps.root, path)) ?? "(missing)"}`;
  const parts = [`## ${gate} · ${change.slug}`, `**${GATE_QUESTIONS[gate]}**`];
  if (gate === "G1") parts.push(await file(pathOf(change, "spec.md")));
  if (gate === "G2") parts.push(await file(pathOf(change, "plan.md")), await file(pathOf(change, "traceability.md")), testList(await testFilesChanged(deps, state, rules, "HEAD")));
  if (gate === "G3") {
    if (state.size === "small") parts.push(await file(pathOf(change, "spec.md")), await file(pathOf(change, "traceability.md")));
    const from = await deps.git.forkPoint(state.base);
    parts.push(await file(pathOf(change, "outcome.md")), fenced("Area spec changes", "diff", await deps.git.diff(from, [AREAS_DIR])), fenced("Files", "", await deps.git.diffStat(from)));
  }
  return parts.join("\n\n");
}

/** G1 covers spec.md. G2 covers spec.md and the approved tests. G3 covers each file that the branch changed, except state.json. */
async function coveredPaths(deps: Deps, change: Change, state: State, rules: Rules, gate: Gate, commit: string): Promise<string[]> {
  if (gate === "G1") return [pathOf(change, "spec.md")];
  if (gate === "G2") return [pathOf(change, "spec.md"), ...(await testFilesChanged(deps, state, rules, commit))];
  const from = await deps.git.forkPoint(state.base, commit);
  return (await deps.git.changedBetween(from, commit)).filter((path) => path !== pathOf(change, "state.json"));
}

async function testFilesChanged(deps: Deps, state: State, rules: Rules, to: string): Promise<string[]> {
  const from = await deps.git.forkPoint(state.base, to);
  return (await deps.git.changedBetween(from, to)).filter((path) => matchesAny(path, rules.testFiles));
}

function testList(paths: readonly string[]): string {
  return `### Tests to approve\n\n${paths.length ? paths.map((path) => `- ${path}`).join("\n") : "- none"}`;
}

function fenced(title: string, language: string, body: string): string {
  return `### ${title}\n\n\`\`\`${language}\n${body || "(no changes)"}\n\`\`\``;
}
```

```ts
      return "approved";
    }
    feedback = [`The person asked for this change: ${answer.feedback}`];
```

```ts
import { mkdir, writeFile } from "node:fs/promises";
import { dirname, join } from "node:path";
import { applyChange, hasRequirement, isFinalId, renderAreaSpec, staleErrors, type AreaSpec, type TestLink } from "../entities/area-spec.js";
import type { Spec } from "../entities/delta.js";
import { errorsOf, type ParseResult } from "../entities/result.js";
import type { State } from "../entities/state.js";
import { requirementLinks, type Traceability } from "../entities/traceability.js";
import { areaFrom, areasOf, areaWithPrefix, readAreas } from "./areas.js";
import { AREAS_DIR, readSpec, readTrace, type Change } from "./change.js";
import type { Deps } from "./ports.js";

export type ShipResult = { errors: string[]; ids: Map<string, string> };
type AreaUpdate = { path: string; text: string; ids: Map<string, string> };

/**
 * Ship steps 2–5: start from the area specs of the base branch, check that the delta is not stale,
 * give the final IDs, and write the area specs. If a check fails, nothing is written.
 */
export async function shipApply(deps: Deps, change: Change, state: State): Promise<ShipResult> {
  const spec = await readSpec(change);
  const trace = state.type === "docs" ? emptyTrace() : await readTrace(change);
  if (!spec.ok || !trace.ok) return { errors: [...errorsOf(spec), ...errorsOf(trace)], ids: new Map() };
  const links = requirementLinks(trace.value.rows);
  const errors: string[] = [];
  const updates: AreaUpdate[] = [];
  for (const name of await areaNames(deps.root, spec.value, links)) {
    const path = `${AREAS_DIR}/${name}.md`;
    const area = areaFrom(name, await deps.git.fileAt(state.base, path), spec.value);
    if (!area.ok) {
      errors.push(...area.errors);
      continue;
    }
    errors.push(...areaErrors(area.value, name, spec.value));
    const result = applyChange(area.value, {
      folder: change.folder,
      delta: spec.value.delta.filter((item) => item.area === name),
      baseline: spec.value.baseline.filter((item) => item.area === name),
      coverage: spec.value.coverage.find((item) => item.area === name)?.text,
      tests: links.filter((link) => belongsTo(link.id, spec.value, area.value, name)),
    });
    updates.push({ path, text: renderAreaSpec(result.area), ids: result.ids });
  }
  if (errors.length) return { errors, ids: new Map() };
  for (const update of updates) {
    await mkdir(dirname(join(deps.root, update.path)), { recursive: true });
    await writeFile(join(deps.root, update.path), update.text);
  }
  return { errors: [], ids: new Map(updates.flatMap((update) => [...update.ids])) };
}

/** The areas of the delta and the baseline, and the areas whose prefix a test link names. */
async function areaNames(root: string, spec: Spec, links: readonly TestLink[]): Promise<string[]> {
  const areas = await readAreas(root);
  const linked = links.filter((link) => isFinalId(link.id)).map((link) => areaWithPrefix(areas, link.id));
  return [...new Set([...areasOf(spec), ...linked.filter((name): name is string => name !== undefined)])];
}

function areaErrors(area: AreaSpec, name: string, spec: Spec): string[] {
  const stale = staleErrors(area, spec.delta.filter((item) => item.area === name));
  const { requirement } = spec;
  const isLost = requirement !== undefined && requirement.startsWith(`${area.prefix}-`) && !hasRequirement(area, requirement);
  return isLost ? [...stale, `${requirement} is not in the area spec any more.`] : stale;
}

/** A link with a final ID belongs to the area of its prefix. A NEW or BASE ID belongs to the area of its delta or baseline item. */
function belongsTo(id: string, spec: Spec, area: AreaSpec, name: string): boolean {
  if (isFinalId(id)) return id.startsWith(`${area.prefix}-`);
  return [...spec.delta, ...spec.baseline].some((item) => item.id === id && item.area === name);
}

function emptyTrace(): ParseResult<Traceability> {
  return { ok: true, value: { head: [], rows: [], footer: [] } };
}
```

```ts
import { realpath, writeFile } from "node:fs/promises";
import { tmpdir } from "node:os";
import { join } from "node:path";
import { upsertSection } from "../entities/markdown.js";
import type { Rules } from "../entities/rules.js";
import { approvalOf, gateAfter, nextStage, stageOf, type State } from "../entities/state.js";
import type { Policy, StageKind } from "../entities/write-policy.js";
import { GATE_QUESTIONS, gateSummary, invalidGates, lockedTests, recordApproval } from "./approve-gate.js";
import { changeOf, pathOf, readRules, readSpec, readState, readText, RULES_PATH, writeState, type Change } from "./change.js";
import { exitErrors, shipErrors } from "./exit-checks.js";
import type { Deps, Finding, ReturnStage, StageRun } from "./ports.js";
import { returnChange } from "./return-change.js";
import { protectedErrors, runChecked, type StageEnd } from "./run-stage.js";
import { setupRules } from "./setup-rules.js";
import { shipApply } from "./ship-apply.js";
import { GUIDES } from "./stages.js";
import { startChange, suggestSlug } from "./start-change.js";

const MAX_REVIEW_ROUNDS = 2;
const RETURN_ORDER: readonly ReturnStage[] = ["spec", "plan", "tests", "build"];

type Step = { kind: "stopped" } | { kind: "next"; state: State };
type Checked = { kind: "passed"; state: State; findings: Finding[] | undefined } | Exclude<StageEnd, { kind: "passed" }>;
type Reviewed = { kind: "reviewed"; state: State; findings: Finding[] };
type Check = (latest: State, findings: Finding[] | undefined) => Promise<string[]>;

const STOPPED: Step = { kind: "stopped" };

/** The /sdd runner: start a change from a request, or continue the change of the current branch. */
export function createRunner(deps: Deps) {
  return {
    start: (request: string) => start(deps, request),
    resume: () => resume(deps),
  };
}

async function start(deps: Deps, request: string): Promise<void> {
  const refusal = await startRefusal(deps);
  if (refusal) return deps.person.notify(refusal, "warning");
  const suggestion = suggestSlug(request);
  const answer = await deps.person.input(`Short name for this change. Leave it empty to use "${suggestion}".`, suggestion);
  if (answer === undefined) return;
  const change = await startChange(deps, { request, slug: answer.trim() ? suggestSlug(answer) : suggestion });
  await drive(deps, change, false);
}

async function resume(deps: Deps): Promise<void> {
  const refusal = await repositoryRefusal(deps);
  if (refusal) return deps.person.notify(refusal, "warning");
  if (await deps.git.isMerging()) return deps.person.notify("Finish the merge first: resolve the conflicts and commit. Then run /sdd again.", "warning");
  const change = changeOf(deps.root, await deps.git.currentBranch());
  if (!change || (await readText(deps.root, pathOf(change, "state.json"))) === undefined) {
    return deps.person.notify("No change runs on this branch. Run /sdd <request> to start one, or switch to its sdd/ branch.", "warning");
  }
  await drive(deps, change, true);
}

async function repositoryRefusal(deps: Deps): Promise<string | undefined> {
  if (!(await deps.git.isRepository())) return "/sdd needs a git repository.";
  if ((await realpath(await deps.git.root())) !== (await realpath(deps.root))) return "Run /sdd from the root folder of the git repository.";
  return undefined;
}

async function startRefusal(deps: Deps): Promise<string | undefined> {
  const refusal = await repositoryRefusal(deps);
  if (refusal) return refusal;
  if (!(await deps.git.isClean())) return "Commit or stash your work first. /sdd needs a clean working tree.";
  if ((await deps.git.currentBranch()).startsWith("sdd/")) return "A change already runs on this branch. Run /sdd with no request to continue it.";
  return undefined;
}

/** Run the stages until the change is done, the person stops it, or a merge conflict needs the person. */
async function drive(deps: Deps, change: Change, resumed: boolean): Promise<void> {
  if (!(await deps.git.isCommitted(RULES_PATH)) && (await setupRules(deps, change)) === "stopped") return;
  let state = await readState(change);
  if (resumed) {
    if ((await deps.git.isClean()) && !(await mergedBase(deps, state))) return;
    state = await reopenInvalidGates(deps, change, state);
  }
  let isResumedStage = resumed;
  while (state.stage !== "done") {
    if (!isResumedStage && !(await mergedBase(deps, state))) return;
    const step = state.stage === "ship" ? await ship(deps, change, state) : await workStage(deps, change, state, isResumedStage);
    isResumedStage = false;
    if (step.kind === "stopped") return;
    state = step.state;
  }
  deps.person.notify(`The change is ready. Merge the branch sdd/${change.folder} into ${state.base}.`, "info");
}

/** Spec, Plan, Tests, or Build: the sessions, the exit check, then the gate or the next stage. */
async function workStage(deps: Deps, change: Change, state: State, resumed: boolean): Promise<Step> {
  const rules = await readRules(deps.root);
  const check: Check = (latest) => exitErrors(deps, change, latest, rules);
  let current = state;
  const hasPassed = resumed && (await check(state, undefined)).length === 0;
  if (!hasPassed) {
    const runs = resumed ? [await stageRun(deps, change, state, rules, state.stage, ["Continue the stage. Read the files to see what is done."])] : await stageRuns(deps, change, state, rules);
    const checked = await checkedStage(deps, change, state, runs, check);
    if (checked.kind !== "passed") return endOf(deps, change, checked);
    current = checked.state;
  }
  await deps.git.commitAll(`sdd(${change.slug}): ${current.stage} passed`);
  return gateOrAdvance(deps, change, current, rules);
}

async function stageRuns(deps: Deps, change: Change, state: State, rules: Rules): Promise<StageRun[]> {
  if (state.stage !== "build" || state.size === "small") return [await stageRun(deps, change, state, rules, state.stage, [])];
  const spec = await readSpec(change);
  const stories = spec.ok ? [...spec.value.stories].sort((a, b) => a.priority - b.priority) : [];
  const storyRuns = await Promise.all(stories.map((story) => stageRun(deps, change, state, rules, `build ${story.id}`, [`Part: the story ${story.id} — ${story.title}.`])));
  return [
    await stageRun(deps, change, state, rules, "build foundation", ["Part: the foundation tasks."]),
    ...storyRuns,
    await stageRun(deps, change, state, rules, "build check", ["Part: the check."]),
  ];
}

async function stageRun(deps: Deps, change: Change, state: State, rules: Rules, title: string, lines: readonly string[]): Promise<StageRun> {
  const kind = kindOf(state.stage);
  const policy: Policy = {
    kind,
    changeDir: change.dir,
    specLocked: approvalOf(state, "G1") !== undefined,
    lockedTests: await lockedTests(deps, state, rules),
    testGlobs: rules.testFiles,
  };
  const message = [
    `Read ${join(deps.guidesDir, GUIDES[kind])} and follow it.`,
    `Change folder: ${change.dir}`,
    `Rules: ${RULES_PATH}`,
    ...(state.stage === "spec" ? [`Request: ${state.request}`] : []),
    ...lines,
  ].join("\n");
  return { title: `sdd: ${title} (${change.slug})`, message, policy };
}

function kindOf(stage: State["stage"]): StageKind {
  return stage === "ship" || stage === "done" ? "review" : stage;
}

/** Run the sessions with the retry loop. A classification from the agent goes into state.json at once. */
async function checkedStage(deps: Deps, change: Change, state: State, runs: readonly StageRun[], check: Check): Promise<Checked> {
  let current = state;
  let findings: Finding[] | undefined;
  const end = await runChecked(deps, {
    runs,
    protect: () => protectedErrors(deps, change, runs[0].policy, current),
    apply: async (outcome) => {
      if (outcome.classification) {
        current = { ...current, ...outcome.classification };
        await writeState(change, current);
      }
      if (outcome.findings) findings = outcome.findings;
    },
    check: () => check(current, findings),
  });
  return end.kind === "passed" ? { kind: "passed", state: current, findings } : end;
}

async function endOf(deps: Deps, change: Change, end: Exclude<Checked, { kind: "passed" }>): Promise<Step> {
  if (end.kind === "stopped") return STOPPED;
  return { kind: "next", state: await returnChange(deps, change, await readState(change), end.request) };
}

async function gateOrAdvance(deps: Deps, change: Change, state: State, rules: Rules): Promise<Step> {
  const gate = gateAfter(state.stage, state.size);
  if (!gate) return { kind: "next", state: await advance(deps, change, state) };
  let current = state;
  for (;;) {
    const answer = await deps.person.gate(`${gate}: ${GATE_QUESTIONS[gate]}`, await gateSummary(deps, change, gate, current, rules));
    if (answer.kind === "stop") return STOPPED;
    if (answer.kind === "approve") return { kind: "next", state: await advance(deps, change, await recordApproval(deps, change, gate, current)) };
    const run = await stageRun(deps, change, current, rules, `${current.stage} change`, [`The person asked for this change at ${gate}: ${answer.feedback}`]);
    const checked = await checkedStage(deps, change, current, [run], (latest) => exitErrors(deps, change, latest, rules));
    if (checked.kind !== "passed") return endOf(deps, change, checked);
    current = checked.state;
    await deps.git.commitAll(`sdd(${change.slug}): ${current.stage} changed at ${gate}`);
  }
}

async function advance(deps: Deps, change: Change, state: State): Promise<State> {
  const next: State = { ...state, stage: nextStage(state) };
  await writeState(change, next);
  await deps.git.commitAll(`sdd(${change.slug}): start ${next.stage}`);
  return next;
}

/** Ship: apply the delta, review, return for findings (at most 2 rounds), then G3. */
async function ship(deps: Deps, change: Change, state: State): Promise<Step> {
  const rules = await readRules(deps.root);
  const applied = await shipApply(deps, change, state);
  if (applied.errors.length) {
    return { kind: "next", state: await returnChange(deps, change, state, { stage: "spec", reason: `The delta is stale: ${applied.errors.join(" ")}` }) };
  }
  await deps.git.commitAll(`sdd(${change.slug}): apply the delta to the area specs`);
  const review = await reviewRound(deps, change, state, rules, applied.ids, []);
  if (review.kind !== "reviewed") return review;
  if (review.findings.length && review.state.reviewRounds < MAX_REVIEW_ROUNDS) return returnForFindings(deps, change, review.state, review.findings);
  return shipGate(deps, change, review.state, rules, applied.ids);
}

async function reviewRound(deps: Deps, change: Change, state: State, rules: Rules, ids: ReadonlyMap<string, string>, lines: readonly string[]): Promise<Step | Reviewed> {
  const diffPath = await writeReviewDiff(deps, change, state);
  const run = await stageRun(deps, change, state, rules, "review", [`Diff of the change: ${diffPath}`, ...lines]);
  const checked = await checkedStage(deps, change, state, [run], (_latest, findings) => shipErrors(deps, rules, change, findings !== undefined));
  if (checked.kind !== "passed") return endOf(deps, change, checked);
  const findings = checked.findings ?? [];
  await writeOutcomeSections(deps, change, ids, findings);
  await deps.git.commitAll(`sdd(${change.slug}): review`);
  return { kind: "reviewed", state: checked.state, findings };
}

async function returnForFindings(deps: Deps, change: Change, state: State, findings: readonly Finding[]): Promise<Step> {
  const stage = RETURN_ORDER.find((candidate) => findings.some((finding) => finding.returnTo === candidate)) ?? "build";
  const reason = `Review findings: ${findings.map((finding) => `${finding.file}: ${finding.problem}`).join("; ")}`;
  const counted: State = { ...state, reviewRounds: state.reviewRounds + 1 };
  return { kind: "next", state: await returnChange(deps, change, counted, { stage, reason }) };
}

async function shipGate(deps: Deps, change: Change, state: State, rules: Rules, ids: ReadonlyMap<string, string>): Promise<Step> {
  let current = state;
  for (;;) {
    const answer = await deps.person.gate(`G3: ${GATE_QUESTIONS.G3}`, await gateSummary(deps, change, "G3", current, rules));
    if (answer.kind === "stop") return STOPPED;
    if (answer.kind === "approve") return { kind: "next", state: await recordApproval(deps, change, "G3", current) };
    const review = await reviewRound(deps, change, current, rules, ids, [`The person asked for this change at G3: ${answer.feedback}`]);
    if (review.kind !== "reviewed") return review;
    if (review.findings.length) return returnForFindings(deps, change, review.state, review.findings);
    current = review.state;
  }
}

/** The reviewer reads the diff from a file outside the project, so the review stage needs no bash. */
async function writeReviewDiff(deps: Deps, change: Change, state: State): Promise<string> {
  const path = join(tmpdir(), `sdd-review-${change.slug}.diff`);
  await writeFile(path, await deps.git.diff(await deps.git.forkPoint(state.base)));
  return path;
}

async function writeOutcomeSections(deps: Deps, change: Change, ids: ReadonlyMap<string, string>, findings: readonly Finding[]): Promise<void> {
  const path = pathOf(change, "outcome.md");
  const text = (await readText(deps.root, path)) ?? `# Outcome: ${change.slug}\n`;
  const idMap = ids.size ? [...ids].map(([local, final]) => `- ${local} → ${final}`).join("\n") : "- none";
  const table = [
    "| # | File | Problem | Action | Return to |",
    "|---|---|---|---|---|",
    ...findings.map((finding, index) => `| ${index + 1} | ${finding.file} | ${finding.problem} | ${finding.action} | ${finding.returnTo} |`),
  ].join("\n");
  await writeFile(join(deps.root, path), upsertSection(upsertSection(text, "ID map", idMap), "Review", findings.length ? table : "No findings."));
}

async function mergedBase(deps: Deps, state: State): Promise<boolean> {
  const merge = await deps.git.mergeBase(state.base);
  if (merge.ok) return true;
  deps.person.notify(`Merging ${state.base} into this branch failed. Resolve the conflicts, commit, and run /sdd again.\n${merge.output}`, "error");
  return false;
}

async function reopenInvalidGates(deps: Deps, change: Change, state: State): Promise<State> {
  const [gate] = await invalidGates(deps, change, state, await readRules(deps.root));
  if (!gate) return state;
  return returnChange(deps, change, state, { stage: stageOf(gate), reason: `A file that ${gate} covers changed after the approval.` });
}
```

```ts
import { relative, resolve, sep } from "node:path";
import type { ExtensionAPI, ExtensionContext, ToolCallEvent, ToolCallEventResult } from "@earendil-works/pi-coding-agent";
import { blockReason, type Policy } from "../entities/write-policy.js";
import { ENTRY } from "../use-cases/ports.js";
import { SDD_TOOLS, STAGE_TOOLS } from "../use-cases/stages.js";

/** The stage of this pi session, if the runner opened it. Each extension instance has its own. */
export type StageContext = { policy: Policy | undefined };

export function createStageContext(): StageContext {
  return { policy: undefined };
}

/** A stage session gets the tools of its stage. Any other session loses the sdd tools. */
export function onSessionStart(pi: ExtensionAPI, stage: StageContext, ctx: ExtensionContext): void {
  stage.policy = stagePolicy(ctx);
  if (stage.policy) pi.setActiveTools([...STAGE_TOOLS[stage.policy.kind]]);
  else pi.setActiveTools(pi.getActiveTools().filter((name) => !SDD_TOOLS.includes(name)));
}

/**
 * Block write and edit calls to paths that the stage cannot write.
 * Bash writes are not visible here: the runner checks the protected paths after each session.
 */
export function guardToolCall(stage: StageContext, event: ToolCallEvent, cwd: string): ToolCallEventResult | undefined {
  if (!stage.policy || (event.toolName !== "write" && event.toolName !== "edit")) return undefined;
  const target = String((event.input as { path?: unknown }).path ?? "");
  const path = relative(cwd, resolve(cwd, target)).split(sep).join("/");
  const reason = blockReason(path, stage.policy);
  return reason ? { block: true, reason } : undefined;
}

function stagePolicy(ctx: ExtensionContext): Policy | undefined {
  for (const entry of ctx.sessionManager.getEntries()) {
    if (entry.type === "custom" && entry.customType === ENTRY.stage) return entry.data as Policy;
  }
  return undefined;
}
```

```ts
import type { ExtensionCommandContext, ReplacedSessionContext, SessionEntry } from "@earendil-works/pi-coding-agent";
import { ENTRY, type Agent, type Finding, type ReturnRequest, type StageOutcome, type StageRun } from "../use-cases/ports.js";
import type { Classification } from "../entities/state.js";

export type PiAgent = Agent & {
  /** The context of the newest session: the start chat, or the last stage session. */
  context(): ExtensionCommandContext;
  /** The last stage session, if the runner opened one. It can show messages. */
  stageSession(): ReplacedSessionContext | undefined;
};

/**
 * Each stage runs in a new pi session under the start chat. pi loads a new extension instance for it,
 * so the policy goes into the session as a custom entry, and the tools report back through custom entries.
 */
export function createPiAgent(start: ExtensionCommandContext): PiAgent {
  const parentSession = start.sessionManager.getSessionFile();
  let current: ExtensionCommandContext = start;
  let stage: ReplacedSessionContext | undefined;
  return {
    context: () => current,
    stageSession: () => stage,
    async run({ title, message, policy }: StageRun): Promise<StageOutcome> {
      let outcome: StageOutcome = { aborted: true };
      const result = await current.newSession({
        parentSession,
        setup: async (sessionManager) => {
          sessionManager.appendSessionInfo(title);
          sessionManager.appendCustomEntry(ENTRY.stage, policy);
        },
        withSession: async (ctx) => {
          current = ctx;
          stage = ctx;
          outcome = await send(ctx, message);
        },
      });
      return result.cancelled ? { aborted: true } : outcome;
    },
    async followUp(message: string): Promise<StageOutcome> {
      if (!stage) throw new Error("A follow-up needs a stage session. Call run first.");
      return send(stage, message);
    },
  };
}

/** What the agent reported in these session entries: a stop by the person, and the last result of each sdd tool. */
export function outcomeOf(entries: readonly SessionEntry[]): StageOutcome {
  return {
    aborted: lastStopReason(entries) === "aborted",
    returnRequest: lastData<ReturnRequest>(entries, ENTRY.returnRequest),
    findings: lastData<{ findings: Finding[] }>(entries, ENTRY.review)?.findings,
    classification: lastData<Classification>(entries, ENTRY.classify),
  };
}

async function send(ctx: ReplacedSessionContext, message: string): Promise<StageOutcome> {
  const before = ctx.sessionManager.getBranch().length;
  await ctx.sendUserMessage(message);
  await ctx.waitForIdle();
  return outcomeOf(ctx.sessionManager.getBranch().slice(before));
}

function lastData<T>(entries: readonly SessionEntry[], customType: string): T | undefined {
  const entry = entries.filter((candidate) => candidate.type === "custom" && candidate.customType === customType).at(-1);
  return entry?.type === "custom" ? (entry.data as T) : undefined;
}

function lastStopReason(entries: readonly SessionEntry[]): string | undefined {
  for (const entry of [...entries].reverse()) {
    if (entry.type === "message" && entry.message.role === "assistant") return entry.message.stopReason;
  }
  return undefined;
}
```

```ts
export function createPiPerson(pi: ExtensionAPI, agent: PiAgent): Person {
  const ui = () => agent.context().ui;

      await showSummary(pi, agent, summary);

      if (choice !== CHANGE) return { kind: "stop" };

    },
    choose: (title, options) => ui().select(title, options),
    input: (title, hint) => ui().input(title, hint),
    notify: (message, level) => ui().notify(message, level),
  };
}

  const session = agent.stageSession();
  if (session) await session.sendMessage(message);
  else pi.sendMessage(message);
```

```ts
import type { ExtensionAPI, ExtensionCommandContext } from "@earendil-works/pi-coding-agent";
import { createGit } from "./adapters/git.js";
import { createPiAgent } from "./adapters/pi-agent.js";
import { createStageContext, guardToolCall, onSessionStart } from "./adapters/pi-guard.js";
import { createPiPerson } from "./adapters/pi-person.js";
import { sddTools } from "./adapters/pi-tools.js";
import type { Deps } from "./use-cases/ports.js";
import { createRunner } from "./use-cases/run-change.js";

const COMMAND_TIMEOUT_MS = 30 * 60 * 1000;

export type SddOptions = { guidesDir?: string };

/** The composition root: the tools, the stage guard, and the /sdd command. Tenon passes guidesDir; terminal pi finds it next to src/. */
export default function tenonSdd(pi: ExtensionAPI, options: SddOptions = {}): void {
  const guidesDir = options.guidesDir ?? join(dirname(fileURLToPath(import.meta.url)), "../guides");
  const stage = createStageContext();
  for (const tool of sddTools(pi, stage)) pi.registerTool(tool);
  pi.on("session_start", (_event, ctx) => onSessionStart(pi, stage, ctx));
  pi.on("tool_call", (event, ctx) => guardToolCall(stage, event, ctx.cwd));
  pi.registerCommand("sdd", {
    description: "Spec-driven change: /sdd <request> starts one, /sdd continues the change of this branch",
    handler: (args, ctx) => runSdd(pi, guidesDir, args, ctx),
  });
}

async function runSdd(pi: ExtensionAPI, guidesDir: string, args: string, ctx: ExtensionCommandContext): Promise<void> {
  if (!ctx.hasUI) return ctx.ui.notify("/sdd needs a person to approve the gates, so it does not run without a UI.", "warning");
  if (!ctx.isProjectTrusted()) return ctx.ui.notify("/sdd runs only in a trusted project.", "warning");
  const agent = createPiAgent(ctx);
  const deps: Deps = { root: ctx.cwd, agent, person: createPiPerson(pi, agent), git: createGit(ctx.cwd), guidesDir, now: () => new Date(), timeoutMs: COMMAND_TIMEOUT_MS };
  const runner = createRunner(deps);
  const request = args.trim();
  try {
    await (request ? runner.start(request) : runner.resume());
  } catch (error) {
    deps.person.notify(`/sdd stopped: ${(error as Error).message}`, "error");
  }
}
```

````markdown
# Stage 1: Spec

You write `spec.md` in the change folder. The spec tells what the user needs and why. It contains no technology words. The runner gave you the change folder and the request. The runner already made the branch, the folder, and `state.json`. You can write only `spec.md`.

## Steps

1. Read `sdd/rules.md` and the area specs in `sdd/areas/` that the request touches.
2. Select the type and the size, and call `classify_change`:
   - feature: new behavior. Always full size.
   - change: changes a requirement that is in an area spec.
   - bug: the code breaks a requirement that is in an area spec. The delta is empty. If no requirement covers the case, the type is change.
   - refactor or chore: no behavior change. The delta is empty.
   - docs: text only. The delta is empty.
   - Small size: one changed requirement or no behavior change, a few files, no new data, no API change. All other changes are full size.
3. If an area spec does not describe the behavior that the change touches, read the code and write a baseline (see "Existing code").
4. Write the goal: the problem, who has it, and why it is important.
5. Split the change into user stories, each with a priority (P1 = necessary). A small change has one story, US1.
6. For each story, write acceptance scenarios as Given / When / Then. Each "Then" must be visible or measurable.
7. Write the delta. A new requirement gets NEW-R1, NEW-R2, and a new quality requirement gets NEW-Q1. Do not write final IDs: Ship gives them. For a new area, write the heading with "(new, prefix ABC)", where ABC is 2 to 8 capital letters.
8. Use the quality checklist. Give each item a measurable target, "rules default", or "N/A + reason". A target that needs a test is a NEW-Q item in the delta.
9. Write the edge cases and the items that are out of scope.
10. For each unclear item, call `ask_owner`: one question at a time, with 2 to 4 options and your recommendation. Write the answer into the requirement that it affects, and record it in Decisions. While a question is open, keep it as a line `- [OPEN] <question>`. No `[OPEN]` line can remain at the end.
11. Stop. The runner checks the spec. If the check fails, you get a message: correct the spec.

## Strict lines

The runner reads these lines. Write them exactly in this form. All other text is free.

- `### US1 — <title> (P1)`
- `- [US1-S1] Given …, When …, Then …`
- Under `## Delta` and `## Baseline (from code)`: `### sdd/areas/<area>.md`, or `### sdd/areas/<area>.md (new, prefix ABC)`
- `- ADDED NEW-R1: <text>`
- `- MODIFIED FAV-R-002: <new text>`, and on the next line `(was: <old text, exactly as in the area spec>)`
- `- REMOVED FAV-R-003: <text, exactly as in the area spec>`, and on the next line `(why: <reason>)`
- In the baseline: `- BASE-R1: <behavior>`, and on the next line `Intended? yes` or `Defect: <what the code does>. Intended? no`
- In the baseline: `Coverage: <parts of the area that have no spec yet>`
- `- [OPEN] <question>`
- Small bug or change: `Requirement: <ID>`
````

````markdown
# Stage 3: Tests

You write the tests before the code exists. Do not write production code in this stage: the runner blocks writes to files that are not test files, `traceability.md`, or `plan.md`.
````
